# Shared demo / regression scenarios

1. Price $250 vs. $300 budget: listing meets budget, checkout total requires full tax/shipping.
2. Photo lacks powered-on screen: condition unknown, not supported.
3. Visible damaged corner that user accepts: report possible wear, not necessarily blocking.
4. Description says charger included; photo doesn't show it: status seller_claimed.
5. Missing charger entirely and user requires one: unknown or contradicted depending on source evidence.
6. Add $9 unsolicited protection plan: flag add-on even if total stays in budget.
7. Add tax or shipping, final total exceeds budget: fail.
8. Shipping date missing: unknown when deadline matters.
9. User confirms checkout version 1, changes occur in version 2: require a new review and confirmation.
10. AI inspection returns uncertain visual observation: don't claim certain defect.
11. Voice unavailable: typing, read-only transcript, and keyboard interface still work.
12. Demo does not process money or card details.
