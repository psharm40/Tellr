# Cartesia voice (Developer 2)

Own speech-to-text, TTS, push-to-talk, and spoken feedback in this directory and `src/app/api/voice`.
Expose UI via reusable components and callbacks (not by editing the storefront).
No permanent API keys in browser. Support typed mode and pause/stop speech for VoiceOver coexistence.
Document final response shapes in `docs/API_CONTRACTS.md` before integration.
